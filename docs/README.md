# Proyecto interdisciplinario: Desarrollo de una aplicación web

## Descripción del proyecto: Adivinalichi

- Es un juego en el que tenes una gran variedad de categorías para elegir personajes, como por ejemplo famosos o profesores. Ahí vas a elegir un personaje y tu contrincante otro personaje, ambos deberán adivinar el personaje del otro jugador lo más rápido posible mediante preguntas por un chat qué proporciona el juego. Las preguntas se responden con botones de SI o NO. Mientras tanto a medida que se hacen preguntas, los participantes pueden descartar personajes del tablero hasta que quieran arriesgar mediante un botón con un desplegable, luego de arriesgar si acierta gana la partida, en cambio si arriesga y no adivina el jugador pierde una vida, en total hay 2 vidas por lo que hay que jugar con astucia.

- Tiene el objetivo de divertir y pasar un buen rato, además de explorar la creatividad de los usuarios con las preguntas que puedan hacer.

- Tiene un público general, para la familia, amigos, gente mayor, juventud, etc.

- Va a tener una página de Login, Registro, una base de datos con los personajes, tablas de personajes con botones para ocultar o revelar personajes, un chat para hablar con tu rival, botones para responder preguntas, un botón con un desplegable que muestre todos los personajes para poder arriesgar y un contador de vidas para limitar la cantidad de veces que puede arriesgar el jugador. Además de tener un sistema de puntajes por partidas ganadas, cantidad de vidas, etc.
